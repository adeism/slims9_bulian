# Draf dokumentasi untuk `slims/SLiMS-9-Documentation`

Folder ini berisi halaman siap-kirim untuk repositori dokumentasi resmi SLiMS 9
(<https://github.com/slims/SLiMS-9-Documentation>), yang dibangun dengan
**Docusaurus** dan berada di subfolder `userguide/`.

Draf ini bukan salinan; ia melengkapi struktur yang sudah ada — khususnya bagian
`development-guide/06-Console/` (Penjelasan, Cara penggunaan, Tarsius, Membuat
Command Sendiri) dan modul panduan pengguna.

## Berkas dan tujuan penempatan

| Draf di repo ini | Tujuan di `SLiMS-9-Documentation` | Untuk siapa |
|---|---|---|
| `userguide/development-guide/06-Console/05-CLI-Anything.md` | `userguide/development-guide/06-Console/05-CLI-Anything.md` | pengembang, admin sistem |
| `userguide/user-guide/Modules/7-CLI-Anything/00_intro.md` | `userguide/user-guide/Modules/7-CLI-Anything/00_intro.md` | pustakawan, kepala perpustakaan |
| `userguide/user-guide/Modules/7-CLI-Anything/01_chatbot.md` | `userguide/user-guide/Modules/7-CLI-Anything/01_chatbot.md` | pustakawan, staf sirkulasi |

Penomoran `05-` pada folder Console melanjutkan urutan `01-Intro`, `02-cara-penggunaan`,
`03-Tarsius`, `04-Membuat Command Sendiri`. Penomoran modul `7_CLI-Anything` adalah
**usulan** — modul pengguna saat ini berhenti di `6_Stocktake`; bila pengelola
dokumentasi lebih suka menempatkannya di tempat lain (mis. dekat modul Sirkulasi),
cukup pindahkan berkasnya.

## Tidak perlu mengubah `sidebars.js`

`userguide/sidebars.js` memakai `{type: 'autogenerated', dirName: '.'}`, sehingga
halaman baru otomatis muncul pada urutan abjad/angka sesuai nama berkas. Tidak ada
daftar menu manual yang perlu disunting.

## Konvensi yang diikuti

Draf mengikuti gaya halaman yang sudah ada:

* **Front-matter** `title` dan `description` (bahasa Indonesia).
* **Bentuk perintah** memakai `php index.php <perintah>` seperti halaman Console yang
  ada, dengan `php tarsius <perintah>` disebut sebagai bentuk singkat.
* Judul bagian memakai `###`, langkah bernomor dengan blok kode bersarang.
* Blok kode `bash` / `php` / `json` sesuai isi.
* Nada kalimat mengikuti halaman Console yang sudah ada (bukan gaya referensi API).

### Yang masih perlu dilengkapi sebelum PR

1. **Tangkapan layar** pada `userguide/static/img/` lalu rujuk dengan `/img/...`:

   | Nama berkas usulan | Isi |
   |---|---|
   | `console-cli-anything-doctor.png` | keluaran `php index.php clianything:doctor --json` |
   | `console-cli-anything-dryrun.png` | dry run `clianything:loan:checkout` |
   | `console-cli-anything-status.png` | respons `GET /status` pada bridge |

2. **Baris `image:`** pada front-matter, mengikuti pola
   `https://static.slims.web.id/docs/<nomor>-<nama>.png` yang dipakai halaman lain.
   Contoh untuk halaman Console: `https://static.slims.web.id/docs/6.5-cli-anything.png`.
3. **Verifikasi tautan relatif** setelah berkas ditempatkan (Docusaurus me-resolve
   tautan relatif terhadap lokasi berkas). Tautan silang yang dipakai:
   * `05-CLI-Anything.md` → `03-Tarsius.md` (satu folder).
   * `7-CLI-Anything/00_intro.md` → `../../../development-guide/06-Console/05-CLI-Anything.md`.
4. **Uji lokal** di repositori dokumentasi:

   ```bash
   cd userguide
   npm install
   npm run start
   ```

5. **Pembacaan ulang oleh pustakawan** untuk halaman `7-CLI-Anything` — bagian
   daftar periksa dan contoh percakapan sebaiknya disetujui orang yang menjalankan
   layanan sirkulasi sehari-hari.

## Cara mengirimkan

```bash
git clone https://github.com/<akun-anda>/SLiMS-9-Documentation.git
cd SLiMS-9-Documentation
git switch -c docs/cli-anything

mkdir -p userguide/development-guide/06-Console \
         userguide/user-guide/Modules/7-CLI-Anything

cp <repo-slims>/docs/slims-documentation/userguide/development-guide/06-Console/05-CLI-Anything.md \
   userguide/development-guide/06-Console/
cp -r <repo-slims>/docs/slims-documentation/userguide/user-guide/Modules/7-CLI-Anything \
      userguide/user-guide/Modules/

git add userguide
git commit -m "docs(console): add CLI-Anything agent-native CLI page"
git push -u origin docs/cli-anything
# lalu buka Pull Request ke branch main
```

Sertakan tautan ke PR fitur pada `slims9_bulian` agar peninjau dapat memverifikasi
perintah, opsi, dan kode galat yang didokumentasikan.

## Catatan tentang `api/` (referensi Doctum)

Folder `api/` berisi keluaran Doctum yang dihasilkan `compose.sh` + `builder.php`
menggunakan `env.php` (lihat `env.example.php`). Kelas baru pada fitur ini berada
di `plugins/Commands/` dan `plugins/cli_anything/`, bukan di `lib/`.

* Jangan menyunting `api/` secara manual.
* Bila `env.php` (`path` dan `excludes`) mencakup folder `plugins`, kelas baru akan
  ikut terdokumentasi saat `compose.sh` dijalankan ulang. Bila tidak, cukup halaman
  panduan ini yang perlu ditambahkan — tidak ada API publik baru di `lib/`.
