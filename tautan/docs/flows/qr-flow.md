# Flow: QR Studio

Goal: Create QR from any asset

Entry: QR Studio → Buat QR, from shortlink/microsite/form detail → Generate QR, campaign wizard auto

Shortest Path: Select source (shortlink/microsite/form/campaign/external) → pick style (color, logo optional, preset) → Download PNG/SVG

Success: QR preview, scan test, tracking enabled if dynamic else static, stats scans

Error: Invalid source, logo too large compress suggestion

Help: QR statis vs dinamis explanation, empty state guidance

Next: Download, add to microsite block, view scan analytics
