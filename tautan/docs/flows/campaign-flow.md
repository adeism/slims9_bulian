# Flow: Campaign Lengkap

Goal: Create campaign with microsite+form+shortlink+QR+analytics one flow

Entry: + Buat Baru → Campaign lengkap, Campaigns → Buat Campaign

Shortest Path Wizard 5 langkah: Identitas (nama,tujuan,logo) → Microsite (template,judul,CTA) → Form (template,field) → Link & QR (auto shortlink custom alias min5 + QR) → Publish (preview semua, test form, publish, download QR, share)

Success: Campaign detail shows Overview+Microsite+Forms+Shortlinks+QR+Media+Analytics+Settings, all linked, unified analytics funnel

Error: Step validation inline, can skip non-critical, publish fail rollback draft retry

Help: Progress indicator Step 2/5, autosave wizard, review page before publish, recommended vs advanced path
