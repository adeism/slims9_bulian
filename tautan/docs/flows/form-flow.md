# Flow: Form Maker

Goal: Create form drag-drop, publish, collect responses

Entry: + Buat Baru → Form, Forms → Buat, from microsite editor, campaign wizard step 3, template

Shortest Path: Pick template (Pendaftaran) → drag 1 field to canvas (default Name Email Phone auto) → Publish → /f/slug + shortlink + QR

Success: Form live, test submission works, response in manager, funnel metrics

Error: Field validation fail, limit reached, one per email duplicate

Help: Three panels explained, keyboard alternative Tab+Enter, help bubble click field for validation, empty canvas guidance

Next: Embed to microsite, shortlink/QR, password/login-only, responses & export, email notif
